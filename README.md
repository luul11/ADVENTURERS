# 冒险者们 V0.3

更新：2026-11-16。制作人：伊玛目的门徒。

这是一个 Phaser 4 + TypeScript + Vite 的纯前端、单机、自适应战棋 Demo。当前支持副本路线、跨场战损、契约收服、共享库存与角色行动方针。

本轮写实基地、12种人类外观、8种怪物身份与Lv5女匪副本见`docx/写实基地与敌人素材接入.md`。

## 1. 当前已实现

启动流程：封面→基地场景→建筑或底栏管理→选择副本→选五人→路线与战斗→Boss或撤离通关。封面组件与样式独立维护。

最新容量、手动搜刮、技能掌握和基地培养规则见`docx/搜刮物资库与基地培养.md`。个人/团队物资、搜刮与高危人类基础规则见`docx/团队物资战利品与人类遭遇.md`，基础规则见`docx/副本远征与队伍扩展.md`。包含八类节点、最大10V10、3至6格法宝行囊、普通敌人收服、事件复活、范围施法和四种行动方针。

| 功能 | 说明 |
| --- | --- |
| 游戏封面 | 全屏幻想插画背景，显示游戏名、版本和制作人；兼容桌面、手机、触摸和键盘 |
| 自适应战场 | 棋盘填满核心区；宽屏三栏、窄屏侧栏抽屉；5×6棋盘，支持格线、缩放和拖动 |

| 回合战斗 | 速度排序；一次移动与一次主动行动；近战/远程普攻、7个独立技能、目标确认与取消 |
| 护甲与穿透 | 普通伤害80/20分流；甲不足转HP；穿透绕甲；治疗削弱，可用修理包恢复护甲 |
| 命中与减益 | 最终命中20%–95%；HP和MP分别低于50%各使闪避−10，可叠加为−20 |
| 借机攻击 | 离开四邻近战范围触发，每人每轮一次；命中截停；脱离消耗主动行动安全撤退 |
| 快捷道具 | 生命药水、魔力药水、契约、复苏石共用团队库存；点击暂停，选目标即用，完成或取消后恢复原模式 |
| 手动/自动 | 敌方始终AI；我方可自由切换控制模式，在已提交动作结束后接管 |
| 无职业技能 | 可学习的技能不受职业限制，只能配置本人已掌握的技能，每人最多3个 |
| 整数角色成长 | 六主属性、固定出生潜力、稀有度与称号、升级整数成长、每级1点自由点 |
| 类型与战力 | 普通物种同规则，按满资源估算战力，不随受伤/耗蓝变化 |
| 副本闭环 | 战损跨场保留；战后返回路线；战败Game Over，Boss与路线撤离均通关 |
| 微动画 | 受击单位轻微位移和柔和染色；远程射线与治疗粒子；不闪屏，不震动镜头 |
| 快照边界 | 战斗快照仍为纯数据接口；基地另有schema 2本地保存 |

图例和独立文字反馈区按要求隐藏；战场范围/路径/目标高亮、角色详情和战斗记录仍可用。当前没有独立可见的数字伤害预览区。

## 2. 启动与构建

在项目目录运行：

```powershell
npm.cmd install
npm.cmd run dev-nolog -- --host 127.0.0.1
```

依赖已安装时省略install。启动前先检查8080端口；本项目服务仍在运行时复用原实例，不重复启动。默认访问 `http://127.0.0.1:8080/`。打开或刷新页面先进入封面，点击开始游戏进入基地，再选五人出发。基地资产与培养自动保存；旧档直接废弃，新档schema为2。

手机访问：

```powershell
npm.cmd run dev-nolog -- --host 0.0.0.0
```

手机与电脑在同一局域网，打开 `http://电脑局域网IP:8080/`；需系统允许开发端口。不要把开发服务器当作正式公网部署。

```powershell
npm.cmd run typecheck
npm.cmd run test:battle
npm.cmd run test:expedition
npm.cmd run build-nolog
```

浏览器回归：先确保8080开发服务和9333端口的专用Chrome调试实例已运行，再执行`npm.cmd run test:ui`。封面、选人、战斗和装备的截图及结果在`.codex/ui-qa/`，不使用个人浏览器资料。

构建输出在 `dist`，可以静态托管，无需业务后端。Windows使用`npm.cmd`避免`npm.ps1`的执行策略限制。

## 3. 推荐试玩顺序

先在封面点击开始游戏进入基地，管理队员、装备与方针；再点进入副本，选择五名队员。可在路线页配置背包与方针，点击亮起的节点前进。

1. **查看角色**：点击棋盘角色或行动序列，桌面左侧显示单位情报；点肖像或属性按钮打开详情。手机先点“小队”展开面板。
2. **管理补给**：选择队员后，点“装备与物资”打开弹窗；物资库可拖拽或点选放入随身背包。行囊只放法宝并按属性门槛生效；药剂与契约统一存团队物资库，不占个人容量。
3. **配置技能**：部署时点“技能”，选择我方角色，为三个槽位选择不同技能；属性不会限制技能选择，但会影响收益。
4. **进入战斗**：点“进入战斗”，金色外框和右侧高亮表示当前行动者。
5. **移动**：点“移动”→点蓝色合法目的格→确认；取消不扣资源。普通移动靠近敌人后再离开可能遭借机截停。
6. **攻击/技能**：点近战、远程或技能→点合法目标→确认。近战普攻1格，远程普攻2–3格；技能看说明。查看别人不会改变实际操作单位。
7. **安全撤退**：尚未移动且主动行动未用时，点“脱离”，再移动；本次不能再攻击或施法。
8. **自动与接管**：点击操作栏金色“自动战斗”按钮开启自动；开启后按钮变为绿色“手动接管”。若有动作正在执行，结算完成后接管剩余机会。
9. **战后选路**：胜利后保留资源并返回路线。战斗中不能撤退；进入撤离节点或击败Boss均为通关。战败结束本局。

每次主动行动只有一次移动和一次攻击/技能/脱离。可以先攻后移，但不能分段移动；手动点“结束”会放弃剩余机会。

### 战场视角

PC和手机都使用剩余视口作为战场，不再为品牌、关卡名或目标说明预留独立行。宽度至少1200px时显示三栏，更窄窗口使用侧栏抽屉。改变窗口大小不会拉伸角色或改变战斗规则。

战场右上角设置可切换格线、威胁、缩放和重置视角，并查看存活数。滚轮缩放，放大后可拖动。窄屏通过操作栏的小队与时序图标打开面板；自动和帮助也在操作栏。

### 快捷键

| 按键 | 操作 |
| --- | --- |
| M | 移动 |
| A / R | 近战 / 远程普攻 |
| S | 展开技能 |
| E | 结束行动确认 |
| Enter / Esc | 确认 / 取消选择 |

目标格仍通过点击/触摸选择，没有方向键棋盘导航。输入框、下拉列表和弹层会拦截战斗快捷键。

## 4. 角色、成长和默认关卡

### 主属性与收益

| 每加1点 | 裸属性收益 |
| --- | --- |
| 体质 | +3最大HP |
| 力量 | +1攻击 |
| 智力 | +1法强 |
| 意志 | +2最大MP |
| 技巧 | +2近战命中、+2远程命中（百分点） |
| 敏捷 | +1基础闪避（上限35）、+1速度 |

六项基础属性均为5，主属性最高100；移动固定3格。角色出生时应用种族初始修正，并抽取2–4个不互斥冲突的人物特性。之后每项出生1–3星，升级时分别+1–2、+2–3、+3–4，再额外给1点自由点。所有结果为整数，没有进度累计。

常人50%（总6–8星）、良才30%（9–11）、卓越10%（12–14）、天才9%（15–16）、天选1%（17–18）。称号来自档位与最高潜力方向，只显示、不额外加成。

普通类型默认生成等级：人类1–10，史莱姆1–5，地精2–8，哥布林3–10；不是各物种的升级上限。所有类型共享成长与自由点公式；种族差异只体现为初始属性修正。

装备位包括武器、防具和背包。法宝放在3至6格行囊中自动生效；消耗品和材料统一在无限团队物资库堆叠。装备只增加最终战斗属性，不增加六项主属性；装备要求只检查裸属性，避免装备互相解锁。详细公式见《战斗数值与种族特性装备专项.md》。

### 当前示例

开局从十名角色中选择五名。默认仗义宋哥、游侠阿兰、冒险者小张、参谋阿阳、铁卫肯子。东哥使用游侠阿兰面板，盾战士小徐使用铁卫定位。完整预设见`docx/角色预设与开局选人.md`。

我方主角为固定Lv.3预设。普通敌人前期Lv.1，后期Lv.2；精英Lv.2，Boss遭遇Lv.3。出生和成长随机独立于命中随机，站位按每场当前HP从高到低安排前后。

中央障碍为C3、C4。每方最多10人。契约只能收服普通敌人，下场才能出战；超员后必须在战后遣散非主角团成员。

### 战力含义

抵近射击：远程普攻和瞄准射击在2格额外获得10个百分点命中，3格保持原值；1格仍不能射击。瞄准射击自身命中修正继续叠加，最终上限95%；法术不受影响。预览、结算与AI使用同一规则。

单位情报和详情显示同一个整数“最终战力”。计算使用最大HP/MP/护甲与最终战斗属性，不取当前消耗，不受低资源闪避减益影响。角色详情同时显示裸战力与装备贡献。

```text
B = 4×maxHp + 2×maxArmor + 6×maxMp
  + 12×attack + 12×spellPower
  + 3×min(120,近战命中) + 3×min(120,远程命中)
  + 10×基础闪避 + 2×速度 + 24×(移动−3)
最终战力 = max(1, floor((10×B+6)/12))
```

通常每主属性点约10战力；命中/闪避封顶后收益不再一致。这是Demo预算估值，不是胜率或实际伤害排名。

## 5. 进度保存与当前限制

- **基地资产、扩容和培养会自动保存。进行中的远征不存档。** 刷新会结束当前远征，已带出的资源不退还；没有云同步。
- 本局战后返回路线并保留HP、MP与护甲；倒下队员由独立事件或复苏石恢复。
- 已保留快照API和版本校验，但不提供存档UI，也不静默读取旧版不兼容快照。
- 副本不提供无限Demo升级。当前没有经验培养或加点洗点；局外成长通过金币扩容与精华培养实现。
- 已有Boss节点、契约收服、战利品、商店和本局共享物资库。成功带回的资产保存于本机浏览器。
- 我方使用`image/roster_heroes`的50张伙伴独立姿态图，原有怪物素材保留。新增东哥、盾战士小徐与哥布林首领图集。AI仍是启发式，不保证最优决策；属性和战力权重仍是调参初值。

## 7. 可复用素材裁切

固定5列、任意N行：待机/头像/近战/远程/战损。直接等分、简单白色阈值转透明，不缩放、不补边、不改原图；已有文件默认不覆盖。

```powershell
python tools/crop_roster.py --input card_roster_5x4_battle_damage.png --rows 4 --names human slime gremlin goblin --output image/roster_5x4_grid
```

重新导出同名文件加`--overwrite`；透明图加`--keep-white`。其他图只需改输入、行数、行名和输出目录。完整说明见`docx/素材裁切使用说明.md`。

## 8. 首批游戏素材

原有20张PNG保留。原两套图集共八名角色40张，新图另外提供四行20张256×256透明PNG。现有十名伙伴50张，精灵预留5张、哥布林首领5张。伙伴按身份区分，普通怪物按物种区分，首领使用独立素材。Vite自动打包。

正常出手切对应姿态；`maxArmor>0 && armor==0`显示战损，重新部署后恢复。治疗不恢复护甲外观。战损出手保持战损图，图片等比显示。

切图遵循简单等分和白色阈值转换；原图排布越格、内部白色被去除等问题不会自动修绘。
